# 엔드포인트 명세

> 아직 작성되지 않음. 엔드포인트가 생길 때마다 추가한다.

htmx 기반이므로 **대부분의 엔드포인트는 JSON이 아니라 Thymeleaf 조각(HTML)을 반환한다.**
JSON을 반환하는 곳은 따로 표시한다.

## 공통

- 인증: 초기 없음 → 익명 세션 쿠키(`owner_key`) → GitHub OAuth (스펙 §2)
- 에러 처리: 미정
- 레이트 리밋: 세션당 LLM 호출 횟수 제한 (스펙 §6)

## 스트리밍

질문 생성은 SSE로 흘려보낸다. 해당 엔드포인트는 `text/event-stream`을 반환하고
클라이언트는 `hx-ext="sse"`로 수신한다.

## 엔드포인트

### (템플릿)

`POST /경로` — 한 줄 설명

| 항목 | 내용 |
| --- | --- |
| 요청 | 폼 필드 또는 본문 |
| 응답 | 반환하는 조각 템플릿 경로 / `text/event-stream` / JSON |
| 대상 | htmx `hx-target` |
| 에러 | 상황별 처리 |

---

## 1단계 예정 (스펙 §5)

JD 붙여넣기 → 파싱 → 질문 10개 스트리밍. 저장·로그인 없음.
구현 시작할 때 실제 경로를 여기에 채운다.
